This is an **interactive, PUBLIC, entirely synthetic demonstration** of the SkyWake Mission Control layout and Neural Universe explorer.

## What works
- Responsive mission cockpit with neural-network and orbital-style visualizations
- Full-screen interactive node graph with pan, zoom, search and category filters
- Right-hand selected-node inspector showing all demo relationships and fields
- Illustrative workflow, decisions, evidence and agent example panels
- Mobile-responsive navigation and keyboard Escape/full-screen exit

## What is intentionally **not included**
- No real SkyWake source documents, file inventory, OneDrive paths, AGENTS.md, internal prompts or sensitive metadata
- No real telescope telemetry, customer/partner activity or financial performance

All 74 nodes, 130 relationships, 10 example files and three sample agent prompts are **fabricated for interface testing**. No scientific or commercial outcome is implied.

The site is a standalone HTML. No external JS/CSS/runtime API dependencies. Source data is included in the file and labeled `PUBLIC_SYNTHETIC_DEMO_NOT_LIVE`.
